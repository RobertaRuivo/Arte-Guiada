# Arte Guiada

Aplicação web interativa desenvolvida para estimular a observação e a interpretação de obras de arte por meio de uma experiência guiada.

Projeto desenvolvido para a disciplina de **Sistemas Computacionais I (SCOM)** — 2026.

## Execução

Clone o repositório e abra o arquivo `index.html` em um navegador.

```bash
git clone <URL_DO_REPOSITORIO>
```

O projeto também está disponível pelo GitHub Pages.

## Tecnologias

* HTML5
* CSS3
* JavaScript
